# 이우드림무역 자금·정산 관리 시스템 (YiwuDream ERP)

중국 구매대행 업무의 **매입 / 매출 / 중국지출 / 해외송금 / 마진 / 세금계산서**를
하나의 웹 프로그램에서 관리하기 위한 사내용 시스템입니다.

> 현재 단계: **설계 단계 (코드 작성 전)**
> 아래 설계 문서를 먼저 검토·확정한 뒤 개발에 착수합니다.

---

## 이 시스템이 기존 엑셀과 다른 점 (설계 5원칙)

| # | 원칙 | 엑셀의 문제 | 이 시스템의 해결 |
|---|------|------------|-----------------|
| 1 | **회사 돈과 고객 돈을 분리한다** | 통장 잔액 = 회사 돈으로 착각 | 고객 예치금(예수금)을 **부채**로 별도 집계, `실제 사용가능 자금` 자동 산출 |
| 2 | **주문(정산번호)이 기준이다** | 입금 1줄 / 지출 여러 줄 → 줄마다 마이너스 마진 | `ORDER-2026-000001` 아래 입금·지출을 모두 연결 → 주문 단위 최종 마진 |
| 3 | **지우지 않는다** | 덮어쓰기, 누가 언제 고쳤는지 모름 | 삭제 대신 **취소(무효화)**, 모든 수정은 `이전값→변경값→수정자→수정시각` 이력 |
| 4 | **환율은 건별 입력** | 고정환율 사용 시 마진 왜곡 | 입금·지출·송금 **건마다 실제 적용환율** 저장 |
| 5 | **세무처리는 설정값** | 시트마다 제각각, 헤더 불명확 | `거래유형` 설정으로 세금계산서 대상금액·부가세 방식 관리 (하드코딩 금지) |

## 검토가 필요한 항목 (대표님 확인 요청)

문서 전반에 `⚠️ 확인필요` 로 표시했습니다. 주요 항목:

1. **엑셀 원본 파일 미첨부** — 이번 세션에 파일이 전달되지 않았습니다. 컬럼 매핑은 설명해 주신 항목명 기준의 **잠정안**이며, 파일 확보 후 확정합니다.
2. **Sheet3의 의미** — CNY/USD/KRW 혼재. 거래처별 미수금인지, 누적 거래액인지 확인 필요.
3. **사이트 수수료의 부가세 포함 여부** — 기본값 설정 필요 (포함 / 별도).
4. **해외송금 루트 매출 인식 기준** — 세무상 중국법인 매출로 볼지, 한국법인 용역매출로 볼지 분리 기록 방식 확정 필요.
