# 이우드림무역 자금관리 — 내 PC에서 실행하기

명령어를 입력하실 필요 없습니다. **딱 두 번 클릭**하면 됩니다.

---

## 처음 한 번만 — Docker Desktop 설치

1. https://www.docker.com/products/docker-desktop/ 에서
   **Download for Windows** 를 눌러 받습니다.
2. 받은 파일을 두 번 눌러 설치합니다. (다음 → 다음 → 완료)
3. 설치가 끝나면 PC를 다시 시작합니다.
4. 시작 메뉴에서 **Docker Desktop** 을 실행합니다.
   화면 아래 고래 아이콘이 **초록색**이 될 때까지 1~2분 기다립니다.

> Docker 는 프로그램이 돌아갈 자리를 만들어 주는 도구입니다.
> 데이터베이스도 여기 안에 같이 들어 있어서 따로 설치하실 필요가 없습니다.

---

## 실행

1. `windows` 폴더를 엽니다.
2. **`시작.bat`** 을 두 번 누릅니다.
3. 검은 창이 뜨고 준비가 진행됩니다.
   - **처음에는 5~10분** 걸립니다. (프로그램을 만드는 중입니다)
   - 두 번째부터는 20초쯤 걸립니다.
4. 준비가 끝나면 **브라우저가 저절로 열립니다.**

### 로그인

| | |
|---|---|
| 주소 | http://localhost:3000 |
| 아이디 | `admin` |
| 비밀번호 | `yiwu-test-2026!` |

직원 화면도 보시려면 아이디 `staff` 로 로그인해 보세요. (비밀번호 같음)
회사 마진과 통장 잔액이 안 보이는 것을 확인하실 수 있습니다.

---

## 끄기

`windows` 폴더의 **`중지.bat`** 을 두 번 누릅니다.
입력하신 자료는 그대로 남습니다. 다시 쓰시려면 `시작.bat` 을 누르세요.

---

## 시연 자료를 처음 상태로 되돌리기

이것저것 눌러 보다가 지저분해지면
**`자료초기화.bat`** 을 누르시고, 다시 `시작.bat` 을 누르세요.

---

## 이 안에 든 자료에 대해

- **전부 가짜입니다.** 실제 회사 거래는 하나도 들어 있지 않습니다.
- 거래처 이름(케이에스글로벌, 네일의품격 등)은 실제 이름을 썼지만
  **금액과 날짜는 전부 만들어 넣은 것**입니다.
- 실제 엑셀을 넣어 보시려면 **관리 → 엑셀 가져오기** 에서 올리시면 됩니다.
  올린다고 바로 들어가지 않고, 무엇이 어떻게 들어갈지 먼저 보여 드립니다.

---

## 안전에 대해

| 항목 | 어떻게 되어 있나 |
|---|---|
| 접근 범위 | **이 PC 에서만** 열립니다 (`127.0.0.1`). 같은 사무실 다른 PC 에서도 안 보입니다 |
| 인터넷 노출 | 없습니다. 바깥에서 접속할 방법이 없습니다 |
| 비밀번호 | 기본값(`yiwudream1234`)이 아닌 테스트용으로 바꿔 두었습니다 |
| 자료 보관 | 이 PC 안에만 있습니다. 어디로도 보내지 않습니다 |

> **HTTPS 를 쓰지 않은 이유**
> 이 PC 안에서만 오가는 통신이라 밖으로 새어 나갈 길이 없습니다.
> 억지로 HTTPS 를 붙이면 브라우저가 「이 사이트는 안전하지 않습니다」 라는
> 빨간 경고를 띄워서 오히려 헷갈리기만 합니다.
> 나중에 사무실 서버에 올려 여러 명이 쓰실 때는 그때 HTTPS 를 붙이는 것이 맞습니다.

---

## 잘 안 될 때

**「Docker Desktop 이 실행되어 있지 않습니다」**
→ 시작 메뉴에서 Docker Desktop 을 먼저 실행하고, 고래 아이콘이 초록색이 될 때까지
   기다린 뒤 `시작.bat` 을 다시 누르세요.

**브라우저에 아무것도 안 뜰 때**
→ 1~2분 더 기다렸다가 http://localhost:3000 을 직접 열어 보세요.
   처음 실행은 시간이 걸립니다.

**그 밖의 오류**
→ 검은 창에 나온 메시지를 그대로 알려 주시면 확인하겠습니다.
