# 02. 업무 분석

> 01번 문서의 실제 엑셀 분석 결과를 반영한 업무 구조 정리입니다.

## 1. 두 개의 자금 주체

```
[한국] 이우드림무역                      [중국] 별도 중국법인
 ├ 일반통장  (KRW)  ──── 자체송금 ────→  └ 중국 회사계좌 (CNY)
 ├ 법인통장  (KRW)   USD 1,110,000          ├ 한국고객 해외송금 직수취
 └ 사이트 결제계좌 (KRW) · 신규             ├ 상품대금/검품/포장/작업비 지급
                                            └ 직원급여/사회보험/사무실 운영비
```

엑셀에서 확인된 사실:

- 해외송금 시트의 `이우드림` 16건(USD 1,110,000 → CNY 7,516,792)이 **한국법인 → 중국법인 자체 송금**입니다. 고객 거래가 아닙니다.
- 그런데 이것이 해외송금 총 도착액의 **33.7%**를 차지하면서 매출로 집계되고 있습니다.

→ 시스템에서는 `entity`(KR / CN)로 자금 주체를 나누고, 자체 송금은 **내부 자금이동 전표**로 따로 둡니다. 매출·마진 어디에도 들어가지 않습니다.

| 코드 | 루트 | 주체 | 통화 | 4개월 실적 | 매출 인식 |
|------|------|------|------|-----------|----------|
| `OVERSEAS` | 해외송금 | 중국법인 | CNY | 도착 CNY 22,272,750 (이우드림 자체분 7,516,792 포함) | 총액 |
| `BANK_GEN` | 일반통장 | 한국법인 | KRW | 입금 KRW 318,254,875 · 거래처 11곳 | 총액 |
| `BANK_CORP` | 법인통장 | 한국법인 | KRW | 입금 KRW 1,150,269,187 · 거래처 191곳 | 총액 |
| `SITE` | 사이트 결제 | 한국법인 | KRW | **엑셀에 없음 (신규)** | **순액** |

### A. 해외송금 — 실제 구조

```
일자 / 거래처 / USD(이보이스) / CNY(도착금액) / CNY(지출금액) / 인건비용 / 기타비용 / 마진 / %
마진 = CNY도착 − CNY지출 − 인건비 − 기타비        (수식 415건 전부 동일)
```

- USD 인보이스는 통관 서류용입니다. **마진은 CNY 도착금액 기준**입니다.
- 전체 446행 중 **264행(59%)이 지출만 있는 행**입니다. 입금은 앞선 다른 행에 있습니다.
- 인건비 기입은 48건, 기타비는 10건뿐 — 대부분 상품대금 하나로 처리.

### B. 일반통장 — 순수 예치금 계좌로 확인됨

```
일자 / 거래처 / KRW입금액 / CNY(환율적용) / CNY지출 / 대행통관비 / 인건비 / 기타비 / 마진 / %
마진 = CNY환산 − 지출 − 통관비 − 인건비 − 기타비
비용 3개 열은 전부 CNY
```

- 거래처가 **11곳뿐**이고 그중 `에이스`가 57건입니다. 특정 고객 전용 계좌가 맞습니다.
- 입금 65건 / **지출만 45건**, 지출 합계가 입금 환산액보다 **CNY 26만 많습니다.**
  → 이전에 받아둔 예치금 잔액에서 계속 빠져나가는 구조입니다.
- 메모에 `收50万 结2107.5` (50만 받고 2,107.5 정산) 같은 기록이 있습니다.

**⭐ 확인 결과 (2026-09-13)**: 대표님 확인 결과 **넘어올 예치금 잔액은 없습니다.**
따라서 이 CNY 264,329 차액은 예치금 소진이 아니라 **미수금**입니다.
거래처별로 쪼개 보니 **에이스 한 곳에서 CNY 341,471**이 나왔고,
입금 없는 지출만 44건 **CNY 368,822**(약 8,100만원)였습니다.
나머지 9개 거래처는 전부 흑자입니다.

→ **미수금(받을 돈)** 을 별도 지표로 관리합니다. 예치금 원장 구조는 사이트 결제 루트를 위해 유지합니다.

### C. 법인통장 — 가장 정상적이지만 세금계산서는 1/4만

```
A~J열: 일반통장과 동일 구조
C열 "KRW 입금액"  → 실제로는 공급가액 (부가세 제외)   ⭐ 헤더가 틀림
M열(헤더없음)     → 실제 입금액 = C × 1.1
N열(헤더없음)     → =M/1.1 = 공급가액 (C와 중복)
```

**⭐ 대표님 확인**: 고객이 실제 입금한 금액은 **M열**이고, C열에는 **부가세를 뺀 금액**을 적어 넣으셨습니다.

- 입금 있는 행 483건 중 **M열에 값이 있는 행은 114건(23.6%)** 뿐입니다.
- 발행분: 실제입금 247,456,552 / 공급가액 224,523,188 / **부가세 22,933,364**
- 마진은 공급가액 기준으로 계산하는 것이 맞습니다 (부가세는 낼 돈이므로).
- 다만 **계좌 잔액은 M 기준**이어야 하므로, 시스템은 입금액(M)과 매출(C)을 나눠 저장합니다.
- ⚠️ 미발행 369건도 부가세를 받으셨는지 확인 필요 — 9,200만원이 갈립니다.

→ 루트만 보고 "법인통장이니까 세금계산서 발행"으로 자동 판단하면 안 됩니다. **주문별 발행여부 플래그**가 필요합니다.

### D. 사이트 결제 — 신규

엑셀에 해당 시트가 없음을 확인했습니다. 완전히 새로 만듭니다.

```
고객 입금 1,100,000원
 ├ 상품구매 예치금 1,000,000원  → 고객 돈. 중국으로 보내야 할 의무
 └ 구매대행 수수료   100,000원  → 회사 수익
```

- 반드시 구분: `총 입금액 / 상품구매 예치금 / 구매대행 수수료 / 송금예정금 / 송금완료금 / 미송금 잔액`
- 세금계산서는 **수수료 기준**으로 발행
- ✅ **수수료는 부가세 포함으로 확정** (대표님 확인). 100,000원 → 공급가액 90,909 / 부가세 9,091
- 부가세 9,091원은 국세청에 낼 돈이므로 **마진은 공급가액 기준**으로 계산합니다

## 4. 주문번호가 필요한 이유 — 엑셀에 이미 흔적이 있습니다

거래처명 칸에 이렇게 적혀 있습니다.

```
아르미르샵49 · 아르미르샵50 · 아르미르샵51 ... 아르미르샵133   (82건)
```

한 거래처에 번호를 붙여 건별로 관리하고 계십니다. 엑셀에 주문번호 칸이 없어서 **거래처명 칸을 주문번호 칸으로 쓰고 계신 것**입니다.

### 문제 상황 (해외송금 시트 실제 데이터)

```
 4행  05-05  코러스 코리아            지출 8,384    → 마진 −8,384   (−100%)
 5행  05-05  코러스 코리아            지출 3,726    → 마진 −3,726   (−100%)
22행  05-11  코러스 코리아            지출 2,066.9  → 마진 −2,066.9 (−100%)
33행  05-14  코러스 코리아            지출 11,540   → 마진 −11,540  (−100%)
79행  05-29  코러스코리아  입금 39,733 지출 36,007.9 인건 1,809 → 마진 1,916.1
```

입금이 있는 행 하나에만 마진이 잡히고, 나머지는 전부 −100%로 찍힙니다.

### 해결

```
ORDER-2026-000042  (거래처: 코러스코리아 / 루트: 해외송금 / 정산통화: CNY)
├─ 입금  05-29  CNY 39,733     [기존관리번호: —]
├─ 지출  05-05  상품대금 CNY 8,384
├─ 지출  05-05  상품대금 CNY 3,726
├─ 지출  05-11  상품대금 CNY 2,066.90
├─ 지출  05-14  상품대금 CNY 11,540
├─ 지출  05-29  상품대금 CNY 36,007.90
└─ 지출  05-29  인건비   CNY 1,809
```

- 번호 체계: `ORDER-2026-000001` (연도별 6자리 자동 채번)
- `아르미르샵49` 같은 기존 번호는 **`기존관리번호` 필드에 원문 그대로 보존**합니다.
- 주문 상태: `진행중` → `정산완료` → (필요시) `취소`

## 5. 용어 정의

| 용어 | 정의 |
|------|------|
| **예치금 (고객 예수금)** | 고객이 맡긴 돈 중 아직 매출이 되지 않은 금액. **회사 돈이 아님(부채)** |
| **송금대기금** | 예치금 중 중국으로 보내야 하는데 아직 안 보낸 금액 |
| **구매대행 수수료** | 사이트 루트에서 회사가 취하는 용역 수익 |
| **주문 원가** | 특정 주문에 귀속되는 지출 합계 |
| **운영비** | 주문에 귀속되지 않는 중국법인 공통 비용 |
| **영업마진** | 주문 마진 합계 − 중국 운영비 |
| **정산통화** | 주문 마진을 계산하는 기준 통화 (해외송금=CNY, 그 외=KRW) |
| **마진율** | 마진 ÷ **총입금** × 100 — 엑셀과 분모가 다름 |
| **원가대비 수익률** | 마진 ÷ **총비용** × 100 — 엑셀의 `%` 열과 같은 값 (보조 표시) |
| **내부 자금이동** | 한국법인 → 중국법인 자체 송금. 매출·마진 집계 제외 |
| **미수금 (받을 돈)** | 지출은 나갔는데 아직 입금되지 않은 금액. 받을 자산 |
| **부가세 예수금** | 고객에게 받았지만 국세청에 낼 돈. **회사 돈이 아님** |
| **실제 사용가능 자금** | 전체 계좌잔액 − 고객예치금 − 미지급 비용 − 부가세 예수금 |
