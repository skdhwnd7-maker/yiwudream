# 04. 화면 설계

> 대상: **PC 브라우저 (1440px 기준)**, 전면 한국어, 사내 전용
> 원칙: 회계 프로그램처럼 복잡하지 않게. 직원은 3~4단계 안에 입력 완료.

---

## 0. 전체 메뉴 구조

```
┌ 이우드림무역 자금관리 ────────────────────────── [김이우/대표] [로그아웃] ┐
│                                                                          │
│ 📊 대시보드        ← 대표님 기본 화면                                     │
│ 💰 자금현황        ← 회사 돈 vs 고객 돈                                    │
│ 📝 거래관리                                                               │
│    ├ 거래(주문) 목록                                                      │
│    └ ➕ 새 거래 등록                                                       │
│ 🏢 거래처관리                                                             │
│ 🌏 해외송금관리                                                           │
│ 🧾 세금계산서관리                                                          │
│ 🇨🇳 중국 운영비                                                           │
│    ├ 직원 급여                                                            │
│    ├ 임시공 비용                                                          │
│    └ 사무실 경비                                                          │
│ 📥 엑셀 가져오기                                                           │
│ ⚙️ 설정  (계좌 / 비용분류 / 거래유형 / 사용자)                              │
│ 📜 변경이력                                                               │
└──────────────────────────────────────────────────────────────────────────┘
```

**대표님이 이 한 화면에서 알 수 있는 것**
- 이번 달 얼마 벌었는지 → `최종영업마진`
- 고객 돈을 얼마 갖고 있는지 → `고객 예치금`
- 중국으로 얼마 보내야 하는지 → `중국 송금대기금`
- 거래처별로 얼마 남는지 → `거래처별 순위`
- 중국 운영비가 얼마인지 → `중국 운영비` 박스
- 세금계산서 얼마 발행해야 하는지 → `발행 예정`

│  ── 거래처별 예치금 잔액 ──────────────────────────────────           │

## 5. ➕ 새 거래 등록 (4단계 위저드) ⭐

> **요구사항: "거래처 선택 → 루트 선택 → 입금액 입력 → 지출 추가 → 자동 계산"**

```
STEP 1 ─ 거래처 선택
  [ 거래처 검색 ▼ ]   ○○상사
  → 선택 즉시 그 거래처의 기본 루트 / 기본 거래유형 자동 세팅
  → 현재 예치금 잔액 표시:  "현재 예치금 25,000,000원 보유 중"

STEP 2 ─ 돈이 들어온 루트 선택
  [ 🌏 해외송금 ] [ 🏦 일반통장 ] [ 🏛 법인통장 ] [ 🛒 사이트 ]
  → 거래처 기본 루트가 미리 선택됨 (변경 가능)

STEP 3 ─ 입금 입력   (루트별로 화면이 달라짐)

  ▸ 해외송금 선택 시
      일자 [2026-05-01]  USD 인보이스 [ 3,500.00 ]
      CNY 실제 도착금액 [ 25,000.00 ]   ← 마진 기준
      수취계좌 [중국법인 ▼]

  ▸ 일반통장 / 법인통장 선택 시
      일자 [2026-05-01]  KRW 입금액 [ 5,000,000 ]
      적용환율 [ 195.0 ] ← 오늘 참고환율 194.8 자동 제안
      → 환산 CNY 25,641.03 (자동표시)
      □ 예치금으로 적립 (주문에 바로 매출 처리하지 않음)
      □ 예치금에서 충당 (신규 입금 없이 기존 예치금 사용)

  ▸ 사이트 선택 시  ⭐
      일자 [2026-05-01]  총 입금액 [ 1,100,000 ]
      ┌─────────────────────────────────────────┐
      │ 상품구매 예치금 [ 1,000,000 ]            │
      │ 구매대행 수수료 [   100,000 ]  (9.09%)   │
      │ 합계 확인       1,100,000 ✓              │
      └─────────────────────────────────────────┘
      → 수수료율 입력 시 자동 분할, 금액 직접 수정도 가능
      → 합계가 안 맞으면 저장 버튼 비활성화

STEP 4 ─ 완료
  ✅ ORDER-2026-000129 생성됨
  [ 지출 바로 추가 ]  [ 목록으로 ]
```
