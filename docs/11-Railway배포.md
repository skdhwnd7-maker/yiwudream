# Railway 에 올리기 — 클릭 순서대로

대표님 PC에 아무것도 설치하지 않습니다. 웹 화면에서 버튼만 누르시면 됩니다.
끝나면 `https://…` 주소가 하나 생기고, 대표님도 직원분들도 그 주소로 들어가 씁니다.

전부 합쳐 **15분쯤** 걸립니다.

---

## 준비물

- GitHub 계정 (이미 있으십니다 — `skdhwnd7-maker`)
- 결제 카드 (Railway 는 무료 체험 후 월 5달러 선입니다. 가입할 때 금액을 확인해 주세요)

---

## 1. 가입

1. https://railway.com 에 들어갑니다.
2. **Login** → **Login with GitHub** 를 누릅니다.
3. GitHub 이 "Railway 가 접근해도 되겠냐" 고 물으면 **Authorize** 를 누릅니다.

---

## 2. 프로젝트 만들기

1. **New Project** 를 누릅니다.
2. **Deploy from GitHub repo** 를 고릅니다.
3. 목록에서 **`skdhwnd7-maker/yiwudream`** 를 고릅니다.
   - 목록에 없으면 **Configure GitHub App** 을 눌러 이 저장소를 허용해 주세요.
4. 만들어진 네모 상자(서비스)를 누릅니다.

> 브랜치는 바꾸지 않으셔도 됩니다. 저장소의 기본 브랜치가 이미 맞춰져 있습니다.
>
> 이때 한 번 빌드가 시작되는데, 아직 데이터베이스가 없어서 실패합니다. 정상입니다. 그냥 두고 다음으로 갑니다.

---

## 3. 데이터베이스 붙이기

1. 프로젝트 화면에서 **New** (또는 **+ Create**) → **Database** → **Add PostgreSQL** 을 누릅니다.
2. `Postgres` 라는 상자가 하나 더 생깁니다. 이게 자료를 보관하는 곳입니다.

---

## 4. 값 넣기 (여기가 제일 중요합니다)

프로그램 상자(`yiwudream`)를 누르고 → **Variables** 탭 → **New Variable** 로 아래를 하나씩 넣습니다.

| 이름 | 값 |
|---|---|
| `DATABASE_URL` | `${{Postgres.DATABASE_URL}}` ← **이 글자 그대로** 넣습니다 |
| `SEED_ADMIN_PASSWORD` | 대표님이 정한 새 비밀번호 |
| `SEED_DEMO` | `1` |

`DATABASE_URL` 은 직접 주소를 적는 게 아니라 **`${{Postgres.DATABASE_URL}}`** 라고 적습니다.
"옆에 있는 Postgres 상자에서 가져다 쓰라"는 뜻입니다. 나중에 주소가 바뀌어도 알아서 따라갑니다.

나머지(`AUTH_SECRET`, `COOKIE_SECURE`, `PORT`)는 **넣지 않으셔도 됩니다.** 프로그램이 알아서 정합니다.

> 올리신 엑셀 원본은 데이터베이스에 함께 보관합니다. 따로 자리를 만드실 필요가 없습니다.

---

## 5. 주소 만들기

1. 프로그램 상자 → **Settings** 탭 → **Networking**
2. **Generate Domain** 을 누릅니다.
3. `https://yiwudream-production-xxxx.up.railway.app` 같은 주소가 생깁니다. 이게 접속 주소입니다.

---

## 6. 켜기

1. 오른쪽 위 **Deploy** (또는 **Redeploy**) 를 누릅니다.
2. **Deployments** 탭에서 진행 상황이 보입니다. 처음에는 5~10분 걸립니다.
3. 기록에 아래가 나오면 다 된 것입니다.

```
  [1/5] 데이터베이스 연결 확인  ... 됐습니다
  [2/5] 표 만들기
  [3/5] 보호장치 적용
  [4/5] 로그인 보안키 확인
  [5/5] 시연 자료 준비
   준비를 마쳤습니다.
```

4. 5번에서 만든 주소로 들어가 로그인합니다.
   - 아이디 `admin`, 비밀번호는 4번에서 넣으신 값

---

## 7. 직원 계정 만들기

로그인한 뒤 **설정 → 사용자 권한** 에서 만드십니다.

- **대표** — 전부 보고 전부 고칠 수 있습니다
- **직원** — 입력만 합니다. 회사 마진·통장 잔액은 보이지 않습니다
- 누가 무엇을 고쳤는지는 **변경이력** 에 전부 남습니다

---

## 실제 자료로 바꿀 때 — 시연 자료 지우기

구경이 끝나고 진짜로 쓰기 시작하실 때만 하십시오.
**시연 거래가 전부 지워집니다. 되돌릴 수 없습니다.**

데이터베이스를 직접 만지실 필요 없습니다. 값 두 개만 바꾸시면 됩니다.

1. 프로그램 상자 → **Variables**
2. `SEED_DEMO` 값을 **`0`** 으로 바꿉니다 (시연 자료를 다시 넣지 않게)
3. **`+ New Variable`** 로 **`RESET_DATA`** = **`1`** 을 넣습니다
4. **Deploy** 를 누릅니다
5. 기록에 이게 나오면 다 지워진 것입니다

```
  [4/6] 자료 초기화 확인
        거래 16건을 포함해 표 27개를 비웁니다.
        비웠습니다. 이제 빈 장부입니다.
        ⚠ Railway 의 RESET_DATA 값을 지워 주세요.
```

6. **`RESET_DATA`** 를 지웁니다 (⋮ → Delete). 다음 배포부터 깔끔합니다.

> **깜빡하고 안 지우셔도 자료는 날아가지 않습니다.**
> 같은 값으로는 딱 한 번만 지웁니다. 두 번째부터는
> `이미 초기화한 값입니다. 자료를 건드리지 않습니다` 라고만 나오고 넘어갑니다.
> 나중에 또 비우고 싶으시면 값을 다른 것으로 바꾸십시오 (`1` → `2`).

### 지워지는 것과 남는 것

| | |
|---|---|
| **지워집니다** | 거래·입금·지출·해외송금·세금계산서·급여·임시공·거래처·변경이력·주문번호 |
| **남습니다** | 계좌 4개, 거래유형 6개, 비용분류 13개, 관리자(admin) 계정 |

`staff` 계정은 지워집니다. 필요하시면 **설정 → 사용자 권한** 에서 다시 만드십시오.

### 그 다음에 하실 일

1. **설정 → 계좌 관리** — 통장 4개의 **기초잔액**을 실제 잔액에 맞춰 넣으십시오.
   이걸 안 넣으면 자금현황 숫자가 실제와 어긋납니다.
2. **거래처 관리** — 거래처를 등록하십시오.
3. **관리 → 엑셀 가져오기** — 기존 엑셀이 있으면 올리십시오.
   바로 들어가지 않고 무엇이 어떻게 들어갈지 먼저 보여 드립니다.

---

## 잘 안 될 때

**"데이터베이스에 연결하지 못했습니다"**
→ `DATABASE_URL` 값이 `${{Postgres.DATABASE_URL}}` 인지 확인하십시오. 중괄호가 두 겹입니다.

**빌드는 됐는데 화면이 안 열린다**
→ 5번의 **Generate Domain** 을 누르셨는지 확인하십시오.

**로그인했는데 바로 로그아웃된다**
→ 주소가 `https://` 로 시작하는지 보십시오. `http://` 로 들어가면 로그인 쿠키가 막힙니다.

**"SEED_ADMIN_PASSWORD 가 필요합니다" 하고 멈춘다**
→ 4번의 비밀번호를 안 넣으신 것입니다. 넣고 Redeploy 하십시오.

---

## 비용을 줄이시려면

Railway 는 쓴 만큼 냅니다. 사무실에서만 쓰신다면 **Settings → Serverless** 를 켜두면
아무도 안 쓸 때 저절로 쉬었다가, 누가 들어오면 몇 초 뒤 깨어납니다.
