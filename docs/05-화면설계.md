# 05. 화면 설계

> 대상: **PC 브라우저 (1440px 기준)**, 전면 한국어, 사내 전용
> 화면의 숫자는 **실제 엑셀 데이터**에서 가져왔습니다.

---

## 0. 메뉴 구조

```
┌ 이우드림무역 자금관리 ────────────────────────── [김이우/대표] [로그아웃] ┐
│ 📊 대시보드          ← 대표님 기본 화면                                    │
│ 💰 자금현황          ← 회사 돈 vs 고객 돈                                  │
│ 📝 거래관리  ├ 거래(주문) 목록  └ ➕ 새 거래 등록                          │
│ 🏢 거래처관리                                                             │
│ 🌏 해외송금관리                                                           │
│ 🔁 내부 자금이동     ← 한국법인 → 중국법인 자체 송금 (신규)                 │
│ 🧾 세금계산서관리                                                          │
│ 🇨🇳 중국 운영비  ├ 직원 급여  ├ 임시공 비용  └ 사무실 경비                 │
│ 📥 엑셀 가져오기                                                           │
│ ⚙️ 설정 (계좌 / 비용분류 / 거래유형 / 사용자)                              │
│ 📜 변경이력                                                               │
└───────────────────────────────────────────────────────────────────────────┘
```

## 5. ➕ 새 거래 등록 (4단계)

```
STEP 1 ─ 거래처 선택
  [ 거래처 검색 ▼ ]  코러스코리아
  → 기본 루트·거래유형 자동 세팅
  → "현재 예치금 25,000,000원 보유 중" 표시
  → 유사 이름 경고: "코러스 코리아(별칭)와 같은 거래처입니다" ⭐

STEP 2 ─ 돈이 들어온 루트 선택
  [ 🌏 해외송금 ] [ 🏦 일반통장 ] [ 🏛 법인통장 ] [ 🛒 사이트 ]

STEP 3 ─ 입금 입력 (루트별로 화면이 다름)

  ▸ 해외송금
      일자 [2026-05-29]  USD 인보이스 [ 5,918.88 ]
      CNY 실제 도착금액  [ 39,733.00 ]   ← 마진 기준
      수취계좌 [중국법인 ▼]

  ▸ 일반통장 / 법인통장
      일자 [2026-05-04]  KRW 입금액 [ 3,142,691 ]
      적용환율 [ 218.00 ]  ⓘ 최근 30일 평균 217.4  (참고환율 제안)
      → 환산 CNY 14,416.93 (자동)
      □ 예치금으로 적립   □ 예치금에서 충당
      [법인통장] ☑ 세금계산서 발행 대상   ← 기본값, 건별 해제 가능 ⭐
                 부가세 별도 → 합계 3,456,960원

  ▸ 사이트  ⭐
      일자 [2026-05-01]  총 입금액 [ 1,100,000 ]
      ┌────────────────────────────────────────┐
      │ 상품구매 예치금 [ 1,000,000 ]           │
      │ 구매대행 수수료 [   100,000 ] (9.09%)   │
      │ 합계 확인       1,100,000 ✓             │
      └────────────────────────────────────────┘
      → 합계가 안 맞으면 저장 버튼 비활성

STEP 4 ─ 완료
  ✅ ORDER-2026-000129 생성됨
  [ 지출 바로 추가 ]  [ 목록으로 ]
```
