# 01. 업무 분석

## 1. 회사 구조와 법인 분리

이 시스템은 **두 개의 자금 주체**를 다룹니다. 이를 섞지 않는 것이 설계의 출발점입니다.

```
[한국] 이우드림무역                    [중국] 별도 중국법인
 ├ 일반통장  (KRW)                      └ 중국 회사계좌 (CNY)
 ├ 법인통장  (KRW)                         ├ 한국고객 해외송금 직접 수취
 └ 사이트 결제계좌 (KRW)                    ├ 상품대금 / 검품 / 포장 / 작업비 지급
                                            └ 직원급여 / 사회보험 / 사무실 운영비
```

- 해외송금 루트는 고객 돈이 **한국 계좌를 거치지 않고** 중국법인 계좌로 바로 들어옵니다.
- 따라서 데이터상 `자금주체(entity)`를 **한국법인 / 중국법인** 두 값으로 구분하고,
  계좌·입금·지출 모두 이 값을 갖습니다.
- 대시보드에서는 "합산 보기"와 "법인별 보기"를 토글할 수 있게 합니다.

## 2. 돈이 들어오는 4개 루트

| 코드 | 루트 | 자금주체 | 입금통화 | 핵심 관리 포인트 | 매출 인식 |
|------|------|---------|---------|-----------------|----------|
| `OVERSEAS` | 해외송금 | 중국법인 | CNY (USD 인보이스) | 인보이스 USD ≠ 실제 도착 CNY. **도착금액 기준** 마진 | 총액(GROSS) |
| `BANK_GEN` | 일반통장 | 한국법인 | KRW | 고객별 **예치금 잔액** 관리 (여러 번 입금 → 나중에 사용) | 총액(GROSS) |
| `BANK_CORP` | 법인통장 | 한국법인 | KRW | 세금계산서 발행 대상. 계산 단순 | 총액(GROSS) |
| `SITE` | 사이트 결제 | 한국법인 | KRW | **총입금 = 상품예치금 + 수수료** 분리 필수 | 순액(NET, 수수료만) |

### A. 해외송금 (`OVERSEAS`)

한국 고객이 중국법인 계좌로 직접 송금.

- 기록 항목: 일자 / 거래처 / **USD 인보이스 금액** / **CNY 실제 도착금액** / CNY 상품지출 / 인건비 / 기타비
- 마진 기준 통화 = **CNY**
- USD 인보이스 금액은 통관·서류용 참고값이며 마진 계산에는 사용하지 않습니다. (별도 컬럼 보관)
- 며칠 뒤 상품비·검품비가 추가되므로 **한 줄 = 한 거래가 아니라, 주문번호에 여러 지출을 연결**합니다.

### B. 일반통장 (`BANK_GEN`)

특별 고객 / 기존 거래처를 위한 임시 계좌. 예치금 성격.

- 예: 100만원 × 5회 = 500만원 입금 → 고객별 잔액으로 보유 → 이후 정산 또는 해외송금으로 소진
- 관리 축: **입금금 / 사용금 / 반환금 / 잔액**
- 기록 항목: 일자 / 거래처 / KRW 입금액 / **적용환율(건별)** / 환산 CNY / CNY 지출 / 대행통관비 / 인건비 / 기타비
- ⚠️ 고정환율 절대 금지. 입금·환전 건마다 실제 적용환율 입력.

### C. 법인통장 (`BANK_CORP`)

대행통관, 직접 납품, 전액 세금계산서 발행 업체. 가장 정상적인 거래.

- 기록 항목: 거래처 / 입금액 / 적용환율 / CNY 환산 / 중국 상품비 / 대행통관비 / 인건비 / 기타비
- 엑셀 뒤쪽의 헤더 불명확한 부가세 열 → **공급가액 / 부가세 / 합계금액 / 세금계산서 발행일 / 발행여부** 로 명확히 분리

### D. 사이트 결제 (`SITE`) — 신규

구매대행 사이트 고객 입금. **전액이 회사 수익이 아님.**

```
고객 입금 1,100,000원
 ├ 상품구매 예치금 1,000,000원  → 고객 돈. 중국으로 송금해야 할 의무
 └ 구매대행 수수료   100,000원  → 회사 수익
```

- 반드시 구분: `총 입금액 / 상품구매 예치금 / 구매대행 수수료 / 중국 송금예정금 / 중국 송금완료금 / 미송금 잔액`
- 예시 진행:
  | 시점 | 상품자금 | 송금완료 | 송금대기 |
  |------|---------|---------|---------|
  | 입금 직후 | 1,000,000 | 0 | 1,000,000 |
  | 60만원 송금 후 | 1,000,000 | 600,000 | 400,000 |
- 세금계산서는 **수수료 기준**으로 발행 (`invoice_base = FEE_ONLY`)
- ⚠️ 수수료가 **부가세 포함인지 별도인지**는 거래유형 설정값으로 관리. 프로그램이 임의 확정하지 않음.

## 3. 비용 분류

### 3-1. 주문 원가 (특정 주문에 귀속 가능)

| 분류코드 | 명칭 | 통화 | 비고 |
|---------|------|------|------|
| `GOODS` | 중국 상품대금 | CNY | |
| `LABOR_CN` | 중국 현지 인건비/작업비 | CNY | |
| `INSPECT` | 검품비 | CNY | |
| `PACKING` | 포장비 | CNY | |
| `CUSTOMS` | 대행통관비 | KRW/CNY | 수익 항목이 될 수도 있음(대행통관 수익) |
| `SHIPPING` | 운송비 | CNY/KRW | |
| `TEMP_LABOR` | 임시공 인건비 | CNY | 특정 고객 작업 시 **주문에 귀속** |
| `ETC_ORDER` | 기타 비용 | - | |

### 3-2. 중국 운영비 (회사 공통, 주문 미귀속)

| 분류코드 | 명칭 | 관리 화면 |
|---------|------|----------|
| `SALARY` | 중국 직원 급여 | 급여관리 |
| `INSURANCE` | 사회보험(社保) | 급여관리 |
| `TEMP_LABOR_OP` | 임시공 인건비(공통분) | 임시공관리 |
| `OFFICE` | 중국 사무실 운영비 | 사무실경비 |

> **임시공은 두 성격을 모두 가집니다.**
> 특정 고객 작업 때문에 발생 → 해당 주문에 귀속(원가)
> 일반 창고 작업 → 운영비
> → 입력 시 "귀속 주문" 필드를 비워두면 운영비, 채우면 주문 원가로 자동 분류합니다.

## 4. 주문번호(정산번호)가 모든 것의 기준

### 문제 상황 (현재 엑셀)

```
5/1  고객 입금        +5,000,000
5/3  상품대금 지급    -3,000,000
5/5  검품비           -  200,000   ← 이 줄만 보면 마진 -200,000
5/8  추가 상품비      -  500,000   ← 이 줄만 보면 마진 -500,000
5/10 임시공 작업비    -  150,000   ← 이 줄만 보면 마진 -150,000
```

### 해결

```
ORDER-2026-000001  (거래처: ○○상사 / 루트: 일반통장 / 상태: 진행중)
├─ 입금  5/1   5,000,000원 (환율 195.0 → CNY 25,641.03)
├─ 지출  5/3   상품대금  CNY 15,000
├─ 지출  5/5   검품비    CNY  1,000
├─ 지출  5/8   추가상품  CNY  2,500
└─ 지출  5/10  임시공    CNY    750
─────────────────────────────────────
총입금 CNY 25,641.03 / 총비용 CNY 19,250 / 최종마진 CNY 6,391.03 (24.9%)
```

- 번호 체계: `ORDER-YYYY-NNNNNN` (연도별 6자리 일련번호, 자동 채번)
- 주문 상태: `진행중(OPEN)` → `정산완료(SETTLED)` → (필요 시) `취소(CANCELLED)`
- 주문은 **여러 입금, 여러 지출, 여러 송금**과 연결됩니다 (N:M 허용)

## 5. 용어 정의 (시스템 내 통일)

| 용어 | 정의 |
|------|------|
| **예치금 (고객 예수금)** | 고객이 맡긴 돈 중 아직 우리 매출이 되지 않은 금액. **회사 돈이 아님(부채)** |
| **송금대기금** | 예치금 중 중국으로 보내야 하는데 아직 안 보낸 금액 |
| **구매대행 수수료** | 사이트 루트에서 회사가 취하는 용역 수익 |
| **주문 원가** | 특정 주문에 귀속되는 지출 합계 |
| **운영비** | 주문에 귀속되지 않는 중국 법인 공통 비용 |
| **영업마진** | 주문 마진 합계 − 중국 운영비 |
| **정산통화** | 해당 주문의 마진을 계산하는 기준 통화 (해외송금=CNY, 그 외=KRW) |
| **실제 사용가능 자금** | 전체 계좌잔액 − 고객예치금 − 미지급 비용 |
